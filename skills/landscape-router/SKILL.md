# Landscape Router 配置与排障

本 skill 帮助用户配置、查询和排障 landscape 路由器。

## 使用时机

- 用户询问 landscape 路由器的各项功能如何配置
- 用户报告网络故障(NAT、DNS、PPPoE、防火墙、DHCP、网关等),需要排查
- 用户询问 landscape 路由器某个配置项的含义或推荐值
- 用户希望直接查看或修改路由器状态、配置(可通过 API 等途径代为执行)

## 工作方式

根据用户需求和可用途径灵活选择:

- 讲解:说明配置项的作用、推荐设置与配置步骤
- 代查/代改:通过 API 等可用途径直接查询状态、执行配置修改或触发操作
- 排障:按"现象 → 定位 → 根因 → 修复"的顺序排查,必要时结合路由器的查询能力验证

## 常见功能模块

- NAT(端口转发、静态映射)
- DNS(上游、重定向、规则)
- PPPoE(拨号、认证)
- 防火墙(黑名单、规则)
- DHCP(地址池、选项)
- 网关与路由
