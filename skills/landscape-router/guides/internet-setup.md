# 上网所需配置

## 前提条件

- Linux 内核 ≥ 6.9,启用 BTF/BPF;需 root
- 内存建议 ≥ 2 GiB
- 兼容发行版:Debian 13+、Arch 等;避免安装 NetworkManager
- 端口 53 被占用时(systemd-resolved 等)需先停止占用进程

## 配置步骤

1. **接口分区**:为每个接口分配 zone —— WAN(接光猫/外网)、LAN(接设备);确认接口 `UP` 并开启 BOOT(开机自启)
2. **WAN 连接**(三选一):
   - DHCP 客户端:光猫/上游提供 DHCP 时
   - PPPoE 拨号:光猫桥接时,填账号密码,开启"设为默认路由"
   - 静态 IP:固定地址时,填 IP/掩码/网关,开启默认路由
3. **LAN 地址分配**:开启 LAN 接口的 DHCPv4 服务,配置子网
4. **开启转发与 NAT**:在 WAN 接口开启 **WAN 路由转发**、在 LAN 接口开启 **LAN 路由转发**,并开启 **NAT 服务**

## 常见误区

- **WAN 配好 IP ≠ LAN 能上网**:WAN 网卡有了 IP 后,LAN 设备仍无法上网;必须同时完成上面的第 3、4 步
- **手动配置 IP 无效**:WAN 的 NAT 依赖在 Landscape UI 中配置的 IP 服务。直接用 `ip addr`/`ip route` 手动设置的 IP 不会被 NAT 使用,NAT 不会生效
- **转发服务必须 WAN/LAN 双开**:只开启 WAN 路由转发或只开启 LAN 路由转发都不够,两边都要开

## 警告

- 若管理连接从 **WAN 口**进入,必须先建静态 NAT 映射(把 6443 映射到本机)再开 NAT 服务,否则会失联
- 静态端口映射只作用于 WAN 方向;**LAN 侧访问路由器不需要映射,始终可访问**
- 开 NAT 前 LAN 设备只能访问路由器本身,不能上网,属正常

## 验证

1. 内网设备 `ping 8.8.8.8` 验证连通
2. `nslookup example.com` 验证 DNS 解析
3. 路由器"指标监控 → 连接信息"查看连接状态
